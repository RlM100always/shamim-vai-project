# Applied AI Assignment 1 — Multi-Domain Sentiment Analysis

Project files for the Applied AI coursework. The implementation uses the Johns Hopkins Multi-Domain Sentiment Dataset (version 2.0), option 1, and compares three traditional classifiers with two deep neural networks. See the project archive and files in this folder for setup and execution instructions.

**Status:** code and report draft prepared; official data download and real-data model training remain pending because the build environment could not resolve the JHU download host. No real-data metrics are claimed. Read `BUILD_STATUS.md` before using the report.
